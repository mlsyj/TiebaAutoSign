# 贴吧自动签到

自动签到关注的吧和连签礼。亮屏时检查当天进度，未完成时在后台静默签到，熄屏后暂停后续请求。签到优先使用贴吧官方一键签到，其余逐吧补齐。

## 下载与使用

1. 在 [GitHub Releases](https://github.com/mlsyj/TiebaAutoSign/releases/latest) 下载并安装最新版 APK。
2. 在 LSPosed 中启用模块，作用域选择「百度贴吧」。
3. 打开模块设置，打开「启用自动签到」和「亮屏时自动检查当日签到」两个开关。允许模块使用 Root 和自启动。
4. 重启贴吧进程，确保已登录。系统可能延迟后台检查。

需要 Android 8.0 或更高版本，以及支持 libxposed API 102 的 LSPosed。已适配百度贴吧 **22.9.1.0（369688832）**。

系统强行停止模块后，打开模块或贴吧即可恢复检查。
