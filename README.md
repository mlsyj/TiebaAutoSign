# 贴吧自动签到

LSPosed 模块，自动签到关注的吧及连签礼。本仓库仅提供 APK 和使用说明。

## 下载与适配

在 Releases 下载 `TiebaAutoSign-1.4.1.apk`。

- Android 8.0 及以上，LSPosed 支持 libxposed API 102。
- 适配百度贴吧 **22.9.1.0（369688832）**，其他版本未验证。

## 功能

- 优先使用官方一键签到，逐个补齐低于 7 级及未确认成功的吧。
- 自动签到连签礼，支持每日定时、失败重试和当天去重。

## 使用

1. 安装模块，在 LSPosed 中启用，作用域选择百度贴吧。
2. 打开模块设置，启用自动签到并保存。
3. 重启贴吧进程，登录后等待自动签到。

每日定时默认 **09:00**，可修改；需在模块中授权 Root 定时启动，允许自启动/关联启动，并将后台省电设为“无限制”。系统调度可能延迟，触发时可能将贴吧切到前台；强行停止或清理模块可能导致任务不执行。

当天完成后新关注的吧，可在模块中点击“请求重新签到”，再进入贴吧补签。

## 注意

已实测跨日签到、重启后恢复、官方一键及低等级补签。网络、账号状态和贴吧更新可能影响执行，奖励实际到账未验证。

日志包含贴吧名称、时间和页面网址，反馈前请遮盖个人信息及登录凭据，勿上传数据库备份。
